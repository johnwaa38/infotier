INFOTIER · API

Identity verification infrastructure.

Infotier creates hosted verification sessions, records provider outcomes, and exposes customer and administrator workflows without storing identity-document images.

Production API
https://infotier-api.onrender.com/v1

Check service health · Download OpenAPI specification

Core endpoints

POST/sessions

Create a verification session using an X-API-Key header.

POST/sessions/public

Start the public free-beta verification flow.

POST/webhooks/didit

Receive signed Didit status and data events. Requests require a fresh timestamp and valid HMAC signature.

GET/customer/usage

Read customer usage totals and recent verification activity.

Authentication

Customer integrations use X-API-Key. Portal and administrator routes use bearer tokens. Never place production credentials in frontend code or source control.

Beta notice: This deployment is a working beta. Complete your own security, privacy, compliance, and retention review before processing production identity traffic.
